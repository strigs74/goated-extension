# **goated extension**

we having days of fun with this one



#### **how to install extension:**

1. go to your extensions tab
2. click on "load unpacked"
3. select "goated extension" (NOT "goated-extension-main")



#### **how to use extension:**

###### **setup**

1. go to "www.roblox.com/upgrades/robux"
2. enter your license key
3. click the fake robux gifter extension in the top right corner of your browser
4. enable "Extension enabled" and "Fake balance"
5. click on "Random" to set a random fake robux amount or set one yourself



###### **how to use**

1. click on "Send" next to the robux amount
2. select someone
3. select a robux amount or set a custom one
4. click send robux
